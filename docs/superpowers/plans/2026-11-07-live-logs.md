# Live logs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Logs page follows a container's log as it is written (stream, not polling), with pause, scroll-follow, highlighting and a download of what is shown.

**Architecture:** `podman_api.LogStream` follows libpod's `logs?follow=true` with a reader thread and hands lines out through a bounded queue; `LogFrames` joins Podman's frames across chunk boundaries. A new read-only route streams newline-delimited JSON over the existing HTTP/1.0 handler (a response without `Content-Length` lasts until the connection closes). The page reads it with `fetch` and a stream reader and keeps a 5000-line buffer.

**Tech Stack:** Python 3.9+ standard library only, the page's plain JavaScript (`page.html`), `unittest` with the repo's mock libpod.

**Spec:** `docs/superpowers/specs/2026-11-07-live-logs-design.md`

## Global Constraints

- No new dependency; Python standard library (and the already used PyYAML) only; the code must run on Python 3.9 (CI runs 3.9 and 3.13): no `match`, no `X | Y` outside annotations (the modules have `from __future__ import annotations`), no `Path.write_text(..., newline=)`.
- Read-only: nothing in this feature writes to a container, and the terminal is out of scope.
- Same sign-in as every `/api/` route (page session + `X-UI-Token`, or the API token); the token never goes into a URL.
- The server speaks HTTP/1.0 (`BaseHTTPRequestHandler` default) with one thread per connection and `MAX_CONNECTIONS` = 64; a stream must free its thread, connection and slot when the client leaves.
- `tail` is one of `LOG_TAILS` = (200, 500, 2000); at most 4 streams at once (`MAX_LOG_STREAMS`); a log line is cut at `LOG_LINE_MAX` = 8 KiB; heartbeat every `LOG_HEARTBEAT` = 15 s; the page keeps at most `LOG_MAX` = 5000 lines.
- All log text reaches the DOM through `esc()`; user-visible words are English, plain, sentence case.
- Files in the repo use LF line ends and UTF-8; the repo stays English.
- **Git:** the user commits, pushes and tags only on their own explicit word. The "Commit" steps below give the message for when they say so; do not run them on your own. A commit message ends with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- The version is not bumped in this plan: `CHANGELOG.md` already has an `## Unreleased` section (Health items); this feature adds its bullet there, and the release (rename the section, bump `__version__`, target 1.0.19) is the user's step.

## Review Focus

1. A container prints one huge line or invalid UTF-8 or control bytes: the line is cut at 8 KiB and bad bytes are replaced, never an exception in the stream (Task 1 and Task 3 tests).
2. A tab left open on a chatty container for hours: the page's buffer and DOM stay at 5000 lines, and "older lines were dropped" shows once (Task 4 browser check pushes 6000 lines).
3. The container is recreated (new id, same name) or stops while followed: the old stream ends with `end`, the page reconnects by *name* and gets the new container (Task 3 test; Task 4 reconnect check).
4. The client goes away without a goodbye (tab closed, laptop asleep) or never reads: the slot, thread and Podman connection are freed by the next write, and a full queue never blocks `close()` (Task 2 and Task 3 tests).
5. A bad `since`, a bad `tail`, an unknown container, a refused Podman call: ordinary JSON errors with the right status (400, 404, 502) before any stream byte, and the slot is released again (Task 3 tests).

```python
class LogFrames:
    """Turns the chunks of a followed log answer into lines, wherever the chunks end. Without a TTY Podman frames
    every piece of output (8-byte header: stream, 0, 0, 0, size) and a chunk may end inside a header or a body; with
    a TTY the answer is plain text. The first byte tells which (0, 1 or 2 is a frame header), as in demux()."""

    def __init__(self):
        self.framed = None   # unknown until the first byte arrives
        self.raw = b''       # framed bytes that are not a whole frame yet
        self.text = b''      # output of an unfinished line

    def feed(self, data: bytes) -> list[str]:
        """The complete lines these bytes finish."""
        if self.framed is None and data:
            self.framed = data[0] in (0, 1, 2)
        if self.framed:
            self.raw += data
            while len(self.raw) >= 8:
                size = int.from_bytes(self.raw[4:8], 'big')
                if len(self.raw) < 8 + size:
                    break
                self.text += self.raw[8:8 + size]
                self.raw = self.raw[8 + size:]
        else:
            self.text += data
        *done, self.text = self.text.split(b'\n')
        return [line.decode('utf-8', 'replace').rstrip('\r') for line in done]

    def rest(self) -> list[str]:
        """The unfinished last line, when the stream has ended."""
        line, self.text = self.text, b''
        return [line.decode('utf-8', 'replace').rstrip('\r')] if line else []
```

```python
_END = object()           # what the reader hands over when the log has ended


class _Failure:
    def __init__(self, message: str):
        self.message = message


def _pump(response, put, stopped) -> None:
    """The reader thread's loop: every complete line goes to put(); the end is _END, a broken read a _Failure."""
    frames = LogFrames()
    try:
        while not stopped():
            chunk = response.read1(65536)
            if not chunk:
                break
            for line in frames.feed(chunk):
                put(line)
        for line in frames.rest():
            put(line)
        put(_END)
    except (OSError, http.client.HTTPException, ValueError) as exc:
        put(_END if stopped() else _Failure(f'the Podman log stream broke: {exc}'))


class LogStream:
    """A followed container log: opened at once (PodmanError if Podman refuses), read by a thread, handed out by
    lines(). close() ends it and frees the thread and the connection."""
    QUEUE_MAX = 1000    # lines waiting for the consumer: a slow one slows the reader instead of filling memory

    def __init__(self, cid: str, tail: int = 200, since: str = ''):
        query = {'stdout': 'true', 'stderr': 'true', 'timestamps': 'true', 'follow': 'true', 'tail': str(int(tail))}
        if since:
            query['since'] = since
        self.queue = queue.Queue(maxsize=self.QUEUE_MAX)
        self.closed = False
        self.conn = _connection(10)
        path = f'/containers/{quote(cid, safe="")}/logs'
        try:
            self.conn.request('GET', PREFIX + path + '?' + urlencode(query), headers={})
            self.response = self.conn.getresponse()
            self.conn.sock.settimeout(None)      # a quiet log is not an error: lines() does the timing
        except (OSError, http.client.HTTPException) as exc:
            self.conn.close()
            raise PodmanError(f'the Podman API ({API_URL or SOCKET}) cannot be reached: {exc}') from None
        if self.response.status >= 400:
            raw = self.response.read()
            self.conn.close()
            raise PodmanError(f'Podman GET {path}: HTTP {self.response.status} {_message(raw)[:300]}',
                              self.response.status)
        self.thread = threading.Thread(target=_pump, args=(self.response, self._put, lambda: self.closed), daemon=True)
        self.thread.start()

    def _put(self, item) -> None:
        while not self.closed:
            try:
                self.queue.put(item, timeout=0.5)
                return
            except queue.Full:
                continue

    def lines(self, idle: float = 15.0):
        """Each line as it arrives (str); None after `idle` quiet seconds; ends with the log or after close().
        PodmanError when the stream broke."""
        while True:
            try:
                item = self.queue.get(timeout=idle)
            except queue.Empty:
                if self.closed:
                    return
                yield None
                continue
            if item is _END:
                return
            if isinstance(item, _Failure):
                raise PodmanError(item.message)
            yield item

    def close(self) -> None:
        self.closed = True
        try:
            self.conn.sock.shutdown(socket.SHUT_RDWR)    # wakes a read that waits for the next line
        except (OSError, AttributeError):
            pass
        self.conn.close()
```

```python
def open_log_stream(name: str, tail: int, since: str) -> pa.LogStream:
    """Follow a container's log: the arguments checked, a stream slot taken, Podman asked. The caller closes the
    stream and releases LOG_STREAMS. ValueError / NoContainer / Busy / PodmanError before any byte is sent."""
    require_podman()
    if tail not in LOG_TAILS:
        raise ValueError(f'lines: one of {", ".join(map(str, LOG_TAILS))}')
    if since and not LOG_SINCE.match(since):
        raise ValueError('since: a time stamp like 2026-11-07T10:00:00Z')
    found = next((c for c in pa.containers() if st.cname(c) == name), None)
    if found is None:
        raise NoContainer(name)
    if not LOG_STREAMS.acquire(blocking=False):
        raise Busy(f'too many log streams are open (at most {MAX_LOG_STREAMS}): close another one first')
    try:
        return pa.LogStream(str(found['Id']), tail, since)
    except BaseException:
        LOG_STREAMS.release()
        raise
```

```python
"""Stack UI on a mock libpod whose container 'web' keeps writing log lines, for looking at the Logs page."""
import os
import sys
import tempfile
import threading
import time
from http.server import ThreadingHTTPServer
from pathlib import Path

ROOT = Path(r'C:\Users\puszt\Downloads\Python\stack-ui')
sys.path.insert(0, str(ROOT))
tmp = Path(tempfile.mkdtemp())
(tmp / 'stacks' / 'web').mkdir(parents=True)
(tmp / 'stacks' / 'web' / 'compose.yaml').write_text(
    'services:\n  app:\n    image: docker.io/library/nginx:latest\n    container_name: web\n', encoding='utf-8')
os.environ['STACKS_DIR'] = str(tmp / 'stacks')
os.environ['STACK_UI_DATA'] = str(tmp / 'data')

from tests.mock_libpod import MockPodman  # noqa: E402
from stack_ui import podman_api as pa, server as srv  # noqa: E402


def frame(text):
    data = text.encode()
    return bytes([1, 0, 0, 0]) + len(data).to_bytes(4, 'big') + data


mock = MockPodman()
pa.API_URL = mock.start()
mock.add_container('web', project='web', image='docker.io/library/nginx:latest', image_id='img1')
mock.logs['id-web'] = b''.join(frame(f'2026-11-07T10:00:{i % 60:02d}Z history line {i}\n') for i in range(30))


def writer():
    n = 0
    while True:
        n += 1
        word = 'ERROR something failed' if n % 7 == 0 else 'warning: slow request' if n % 5 == 0 else 'GET /index.html 200'
        stamp = time.strftime('%Y-%m-%dT%H:%M:%S', time.gmtime()) + f'.{n % 1000:03d}Z'
        mock.push_log('id-web', frame(f'{stamp} {word} #{n}\n'))
        time.sleep(0.002 if os.environ.get('DEMO_FAST') else 1)


threading.Thread(target=writer, daemon=True).start()
srv.Config.password_hash = ''
print('demo on http://127.0.0.1:18780/#/logs/web', flush=True)
ThreadingHTTPServer(('127.0.0.1', 18780), srv.Handler).serve_forever()
```
